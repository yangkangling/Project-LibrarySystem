# 图书馆借阅管理系统需求规格说明书

版本：V1.0  
日期：2026-08-19  
依据：当前代码实现，包括 Spring Boot 后端、Vue 管理端、Vue 读者端和初始化演示数据。

## 1. 引言

### 1.1 编写目的

本文档用于说明图书馆借阅管理系统当前已经实现和需要满足的功能需求、数据需求、业务规则、接口范围和验收标准，便于后续开发、测试、运行和答辩说明。

### 1.2 项目范围

系统面向图书馆管理员和普通读者，提供图书资料维护、分类维护、书架位置维护、读者管理、借书办理、还书办理、逾期罚款、冻结账号、读者自助借阅、读者自助还书、续借申请和延期审批等功能。

### 1.3 术语说明

| 术语 | 说明 |
| --- | --- |
| 管理员 | 负责维护图书、读者、分类、书架和借还业务的用户 |
| 读者 | 使用读者自助端查询、借书、还书和申请续借的用户 |
| 图书 | 一本书的书目信息和馆藏汇总，例如书名、ISBN、分类、总数、可借数 |
| 单册 | 图书馆中可实际借出的一本实体书，同一图书可以有多本单册 |
| 套书 | 多册组成的一套图书，例如《倚天屠龙记》第一册到第四册 |
| 借阅记录 | 一次图书借出后产生的业务记录，记录读者、图书、单册、借阅日期、应还日期和归还状态 |
| 续借 | 读者对未归还且未逾期的借阅记录提交延期申请，由管理员审批 |
| 罚款 | 借阅记录逾期后按天计算的金额 |

## 2. 系统概述

### 2.1 系统架构

系统采用前后端结合的单体应用结构：

| 层次 | 技术/模块 | 说明 |
| --- | --- | --- |
| 前端 | Vue 3、Element Plus、Axios、Vite | 提供登录页、管理员端和读者端页面 |
| 后端 | Spring Boot、Spring WebMVC、Spring Data JPA | 提供 REST 接口、业务校验和数据库访问 |
| 数据库 | MySQL | 保存账号、分类、图书、单册、书架和借阅记录 |
| 静态资源 | `src/main/resources/static` | 前端构建后由 Spring Boot 直接托管 |

### 2.2 运行环境

| 项目 | 要求 |
| --- | --- |
| JDK | Java 17 |
| 后端端口 | `8080` |
| 数据库 | MySQL，数据库名 `library_system` |
| 数据库编码 | UTF-8 |
| 前端构建 | `frontend` 目录下执行 Vite 构建 |

## 3. 用户角色与权限

### 3.1 管理员

管理员可使用管理端功能，包括工作台统计、图书分类、图书管理、读者管理、借书办理、还书办理、借阅记录、延期申请、逾期查询和书架查询。

### 3.2 读者

读者可使用自助端功能，包括我的借阅、图书查询、自助还书、我的记录和续借申请。读者端所有业务数据必须基于当前登录会话，不允许前端传入其他读者 ID 查看或修改他人数据。

### 3.3 登录入口

系统首页先选择身份：“您是读者”或“您是管理员”。选择后进入对应登录或注册流程，不再同时展示管理员登录、读者登录和读者注册三个表单。

## 4. 功能需求

### 4.1 登录、注册和密码管理

| 编号 | 需求 |
| --- | --- |
| FR-01 | 系统应支持管理员登录，登录成功后进入管理端。 |
| FR-02 | 系统应支持读者登录，登录成功后进入读者自助端。 |
| FR-03 | 系统应支持读者注册，注册后生成读者账号。 |
| FR-04 | 系统应支持账号修改密码，用户输入原密码和新密码后完成更新。 |
| FR-05 | 系统应支持退出登录，退出后清除当前会话。 |
| FR-06 | 未登录用户访问业务接口时，应提示先登录。 |

### 4.2 管理端工作台

| 编号 | 需求 |
| --- | --- |
| FR-07 | 工作台应展示图书种类、馆藏总量、可借图书、借阅中、读者数量和逾期未还数量。 |
| FR-08 | 工作台应提供快捷入口，可跳转到借书办理、还书办理、新增图书和新增读者。 |
| FR-09 | 工作台近期借阅记录应支持分页显示。 |

### 4.3 图书分类管理

| 编号 | 需求 |
| --- | --- |
| FR-10 | 管理员可新增、编辑、删除图书分类。 |
| FR-11 | 分类名称不能为空，且分类名称不能重复。 |
| FR-12 | 已被图书使用的分类不能直接删除。 |
| FR-13 | 图书新增和编辑时，分类应通过下拉选项选择，不能手工随意填写。 |

### 4.4 图书管理

| 编号 | 需求 |
| --- | --- |
| FR-14 | 管理员可按关键词、分类和状态分页查询图书。 |
| FR-15 | 管理员可新增图书，维护 ISBN、书名、作者、分类、书架位置、馆藏数量和状态。 |
| FR-16 | 新增图书时，书架位置应通过已有书架位置选项选择。 |
| FR-17 | 管理员可编辑图书资料和馆藏数量。 |
| FR-18 | 管理员可启用、停用图书。 |
| FR-19 | 管理员可删除未产生业务冲突的图书。 |
| FR-20 | 图书可借数量不得小于 0，且不得大于馆藏总数。 |
| FR-21 | 馆藏总数变化时，系统应自动同步单册数据。 |

### 4.5 单册编号规则

| 编号 | 需求 |
| --- | --- |
| FR-22 | 系统内部应保存完整单册编号，用于区分具体实体馆藏。 |
| FR-23 | 页面展示时应隐藏内部副本流水，避免编号过长。 |
| FR-24 | 套书展示格式为 `ISBN-套号-册号`，例如 `978000000006-03-001`。 |
| FR-25 | 普通单册书展示格式为 `ISBN-册序号`，例如 `978000000004-001`。 |
| FR-26 | 套书的每一册可单独借阅，但编号必须体现它属于同一套书。 |
| FR-27 | 系统初始化数据应包含多套套书，例如射雕英雄传、神雕侠侣、倚天屠龙记。 |

### 4.6 书架位置管理

| 编号 | 需求 |
| --- | --- |
| FR-28 | 管理员可分页查询书架位置。 |
| FR-29 | 书架位置记录应维护所属图书、书架号、馆藏数量和可借数量。 |
| FR-30 | 借书时应占用一个可借书架位置，还书时应释放对应位置。 |
| FR-31 | 图书表和借阅记录应保留书架位置快照，避免后续书架调整影响历史记录。 |

### 4.7 读者管理

| 编号 | 需求 |
| --- | --- |
| FR-32 | 管理员可分页查询读者，可按借阅证号、姓名、手机号和状态筛选。 |
| FR-33 | 管理员可新增、编辑、启用、停用读者。 |
| FR-34 | 管理员可为读者重置密码，并应明确告知读者新密码。 |
| FR-35 | 读者状态为停用或冻结时，不允许产生新的借阅记录。 |

### 4.8 管理端借书办理

| 编号 | 需求 |
| --- | --- |
| FR-36 | 管理员可选择启用状态读者办理借书。 |
| FR-37 | 管理员可选择启用且有库存的图书办理借书。 |
| FR-38 | 借书可批量选择多本图书，并生成同一批次号。 |
| FR-39 | 同一读者最多同时借阅 3 册未归还图书。 |
| FR-40 | 同一读者不能重复借阅同一本尚未归还的图书。 |
| FR-41 | 存在逾期未还记录的读者，不允许办理新借阅。 |
| FR-42 | 借书成功后，图书可借数、单册状态和书架可借数应同步扣减。 |
| FR-43 | 借阅记录应保存读者、图书、单册和书架快照。 |

### 4.9 管理端还书办理

| 编号 | 需求 |
| --- | --- |
| FR-44 | 还书办理页只显示当前未归还、可以办理还书的记录。 |
| FR-45 | 历史已归还记录应在借阅记录页查看，不混入还书办理页。 |
| FR-46 | 管理员可批量勾选借阅记录归还，也可办理部分归还。 |
| FR-47 | 还书成功后，借阅记录状态变为已归还，并记录归还日期。 |
| FR-48 | 还书成功后，图书可借数、单册状态和书架可借数应同步恢复。 |
| FR-49 | 重复归还同一条借阅记录时，系统应拒绝操作。 |

### 4.10 借阅记录

| 编号 | 需求 |
| --- | --- |
| FR-50 | 管理员可分页查询全部借阅记录。 |
| FR-51 | 借阅记录支持按状态、读者、图书、日期和关键词组合筛选。 |
| FR-52 | 记录列表应展示编号、借阅证号、读者、图书、单册编号、书架位置、借阅日期、应还日期、归还日期、状态等信息。 |
| FR-53 | 借阅记录详情应展示快照信息、罚款信息和续借信息。 |

### 4.11 逾期查询、罚款和冻结账号

| 编号 | 需求 |
| --- | --- |
| FR-54 | 管理员可分页查询逾期未还记录。 |
| FR-55 | 逾期天数按应还日期到当前日期计算。 |
| FR-56 | 逾期罚款按每天 0.50 元计算。 |
| FR-57 | 逾期记录应展示罚款金额、罚款状态和读者账号状态。 |
| FR-58 | 管理员可将罚款标记为已扣款。 |
| FR-59 | 管理员可将罚款标记为免罚。 |
| FR-60 | 管理员可冻结逾期读者账号，冻结后读者不能继续借书。 |

### 4.12 延期申请和审批

| 编号 | 需求 |
| --- | --- |
| FR-61 | 读者可对本人未归还、未逾期且没有待审批续借申请的记录提交延期申请。 |
| FR-62 | 每次续借天数必须大于等于 1 天，且不能超过 90 天。 |
| FR-63 | 续借申请提交后状态为待审批。 |
| FR-64 | 管理员可分页查询待审批延期申请。 |
| FR-65 | 管理员同意延期后，系统应把借阅记录应还日期更新为申请日期。 |
| FR-66 | 已归还、已逾期或已有待审批申请的记录不能重复提交续借申请。 |

### 4.13 读者自助端

| 编号 | 需求 |
| --- | --- |
| FR-67 | 读者端应展示我的借阅信息，包括借阅证号、姓名、当前未还数量和可借上限。 |
| FR-68 | 读者可分页查询可借图书，可按关键词和分类筛选。 |
| FR-69 | 读者自助借书时，可选择默认 30 天还书。 |
| FR-70 | 读者自助借书时，可选择自由借阅天数，最长 90 天。 |
| FR-71 | 默认 30 天模式和自由选择模式下，借出后都允许读者申请续借。 |
| FR-72 | 读者端应提供独立续借板块，集中查看可申请续借的借阅记录。 |
| FR-73 | 读者可分页查看当前未还记录。 |
| FR-74 | 读者可分页查看历史借阅记录。 |
| FR-75 | 读者可自助归还本人未归还记录。 |
| FR-76 | 读者不能查看、续借或归还其他读者的记录。 |

### 4.14 分页和查询

| 编号 | 需求 |
| --- | --- |
| FR-77 | 管理端所有列表页均应显示分页器。 |
| FR-78 | 读者端所有列表页均应显示分页器。 |
| FR-79 | 分页参数应包含页码和每页数量。 |
| FR-80 | 每页数量应限制在合理范围内，避免一次返回过多数据。 |

## 6. 业务规则

| 编号 | 规则 |
| --- | --- |
| BR-01 | 只有角色为 `reader` 且状态启用的账号可以借书。 |
| BR-02 | 停用或冻结读者不能办理新借阅。 |
| BR-03 | 停用图书不能办理新借阅。 |
| BR-04 | 图书可借数量为 0 时不能借出。 |
| BR-05 | 同一读者最多同时持有 3 条未归还记录。 |
| BR-06 | 同一读者不能重复借阅同一本未归还图书。 |
| BR-07 | 读者存在逾期未还记录时，不能办理新的借阅。 |
| BR-08 | 默认借阅期限为 30 天。 |
| BR-09 | 自定义借阅期限最长为 90 天。 |
| BR-10 | 应还日期不能早于当天，且不能超过当前日期后 90 天。 |
| BR-11 | 续借申请必须基于未归还、未逾期、本人所有的记录。 |
| BR-12 | 单次续借最长 90 天。 |
| BR-13 | 已有待审批续借申请时，不能重复申请。 |
| BR-14 | 还书时如果已经逾期，应生成或保留罚款信息。 |
| BR-15 | 罚款金额按逾期天数乘以每天 0.50 元计算。 |
| BR-16 | 管理员可将罚款状态改为已扣款或免罚。 |
| BR-17 | 管理员冻结读者账号后，该读者不能继续借书。 |
| BR-18 | 借书和还书必须同步更新图书库存、单册状态和书架库存。 |
| BR-19 | 借阅记录应保留快照，历史记录不应因图书或读者资料后续修改而改变主要展示信息。 |
| BR-20 | 所有列表页面均应提供分页器，避免只显示固定 5 条造成误解。 |

## 8. 非功能需求

| 编号 | 需求 |
| --- | --- |
| NFR-01 | 系统页面应区分管理员端和读者端，避免身份入口混乱。 |
| NFR-02 | 列表页面应支持分页，页面不应因数据量增加而明显卡顿。 |
| NFR-03 | 后端应对关键业务进行校验，不能只依赖前端限制。 |
| NFR-04 | 借书、还书、续借审批、罚款处理等关键操作应在事务中完成。 |
| NFR-05 | 系统应给出明确中文错误提示，例如库存不足、账号被冻结、超过借阅上限等。 |
| NFR-06 | 页面单册编号应简洁可读，同时后端保留完整内部编号保证数据可追踪。 |
| NFR-07 | 数据库表结构可随实体变化自动更新，适合课程演示和本地开发。 |

## 9. 验收标准

| 编号 | 验收点 |
| --- | --- |
| AC-01 | 打开首页后先选择读者或管理员，再进入对应登录流程。 |
| AC-02 | 读者注册后可以登录读者端。 |
| AC-03 | 修改密码后，旧密码不能继续登录，新密码可以登录。 |
| AC-04 | 管理员新增图书时，分类和书架位置均为可选项。 |
| AC-05 | 图书列表、读者列表、借书候选、还书候选、借阅记录、逾期查询、延期申请、读者端图书和记录列表均显示分页器。 |
| AC-06 | 读者可选择默认 30 天借书，也可选择 1 到 90 天内的自由期限。 |
| AC-07 | 读者端存在独立续借板块，可对符合条件的未还记录提交续借申请。 |
| AC-08 | 管理员端延期申请页可看到待审批申请，并能同意延期。 |
| AC-09 | 同一读者同时借阅超过 3 册时，系统拒绝提交。 |
| AC-10 | 读者有逾期未还记录时，系统拒绝新的借阅。 |
| AC-11 | 还书办理页只显示当前未归还记录，历史记录应在借阅记录页查看。 |
| AC-12 | 逾期记录显示逾期天数、罚款金额、罚款状态和冻结账号操作。 |
| AC-13 | 管理员可将罚款标记为已扣款或免罚。 |
| AC-14 | 管理员冻结读者后，该读者不能继续借书。 |
| AC-15 | 套书编号展示为 `ISBN-套号-册号`，普通书编号展示为 `ISBN-册序号`。 |

## 10. 当前限制和后续扩展

| 编号 | 内容 |
| --- | --- |
| EX-01 | 当前系统适合本地或局域网运行；如果要成为公网网站，需要部署服务器、绑定域名并开放端口。 |
| EX-02 | 当前密码为普通字段保存，正式上线应增加密码加密和更严格的账号安全策略。 |

| EX-05 | 当前初始化演示数据会在启动时规范化部分旧数据，正式生产环境应使用数据库迁移脚本管理版本。 |
